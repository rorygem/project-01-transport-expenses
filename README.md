# Transport Expenses Analysis

## Objective
Analyze transport spending patterns to understand cost drivers and opportunities for savings.

## Data
Personal transport transaction data (anonymized).

## Tools
- Python (Pandas, Matplotlib)
- SQL
- JupyterLab
- GitHub

## Structure
- data/raw: original datasets
- data/processed: cleaned data
- notebooks: analysis notebooks
- sql: SQL queries
- outputs: visualizations and results
